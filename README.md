# moawork
모아워크

## 브랜치 규약

| 접두사 | 용도 | 게이트 | 머지 |
| --- | --- | --- | --- |
| `feat/*` · `fix/*` | 정식 작업 | `scripts/check.sh` 필수 (pre-commit + CI) | PR → T10 검수 → main |
| `wip/*` | **보존 전용** 스냅샷 | **pre-commit 우회 허용** (`--no-verify`) | **머지 금지** |

`wip/*` 는 유실 위험이 있는 작업(공유 워킹트리의 미추적 파일 등)을 일단 원격에 박제해 두는
용도다. 게이트를 통과하지 못한 중간 상태여도 커밋할 수 있게 우회를 허용한다.

- **머지하지 않는다.** main 으로 가려면 `feat/*` 브랜치로 **승격**하고, 그때 정식 게이트
  (`check.sh` + CI + T10 검수)를 전부 통과시킨다.
- 우회는 `wip/*` 에서만 허용된다. `feat/*`·`fix/*`·`main` 에서 `--no-verify` 를 쓰지 않는다.
