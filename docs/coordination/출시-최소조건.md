## 미정 — 조건인지 아직 못 정한 것

정하지 못한 채로 두되, **정하지 못했다는 사실은 적는다.**

- **정산·수납 축의 세 출처 통합** (`BBE-230`·`BBE-231`·`BBE-234`)
  → 같은 금액을 세 곳에서 대조 없이 계산한다. 출시 «전» 인가 «후» 인가?
  → 판단 근거: 지금 화면이 「임시」라고 정직하게 표기하고 있어 거짓말은 아니다.
- **성능 예산** (`BBE-222`·`BBE-223`·`BBE-226`)
  → 보드 전환 직렬 왕복 12단계. 느린 채로 나가도 되는가?
  → `BBE-214` 가 20→12 로 줄여 이미 한 번 개선됐다.
