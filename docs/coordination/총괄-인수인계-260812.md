## 4. ★ 총괄이 지킬 것 — 오늘 belie 가 반복해서 지적한 것들

이 절이 이 문서에서 가장 중요하다. **전임 총괄이 오늘 다 어겼다.**

### ① 눌러보지 않고 완료를 보고하지 마라

`BBE-102` 를 「0번 관문 통과」라고 belie 에게 보고했는데 **진입점이 화면에 없었다.**
belie 가 스크린샷을 보내며 *「장난해? 온보딩이라는 게 어딨으며」* 라고 했다.
→ 화면 관련 판정은 **브라우저로 직접 열어보고** 한다. Cowork 에는 Chrome 도구가 있다.

### ② belie 에게 git 명령을 떠넘기지 마라

**총괄(Cowork)은 파일을 만들 수 있지만 `git push` 를 할 수 없다** (자격증명 없음).
전임 총괄이 이 사실을 설명하지 않고 belie 에게 `git add`·`commit`·`push` 를 계속 시켰다.
belie: *「이거 몇 번째 하고 있는 건데 계속 실패하는 것 같거든? 그냥 클로드코드한테 시키는 프롬프트 줘」*

→ **저장소 쓰기는 각 반의 `05` 칸이 겸한다.** 총괄은 «무엇을 올려야 하는지» 만 지정한다.

### ③ 「어떻게 하지?」 보다 「누가 하면 되지?」 를 먼저 물어라

40칸이 놀고 있는데 belie 를 터미널 앞에 앉혀 두는 일이 하루 종일 반복됐다.
belie: *「진즉에 이렇게 얘기할 것이지」*

**belie 손이 필요한 것은 셋뿐이다 — 계정·비밀값 / 승인 판단 / 눈으로 보는 확인.**
그 밖의 것을 시키면 그것은 총괄이 판단을 미룬 것이다.

### ④ 묻지 말고 역제안해라 (`AGENTS.md` §8.4)

라운드가 끝나면 「무엇을 할까요?」가 아니라
**「이렇게 하겠습니다 · 당신 손이 필요한 건 이것뿐입니다」** 로 낸다.

### ⑤ 선택형 팝업(AskUserQuestion)을 쓰지 마라

belie 지침이다. **선택지는 답변 말미에 글로** 제시한다.

### ⑥ 코드·명령을 줄 때 우리말 풀이를 같이 달아라

belie 는 코딩을 배운 적이 없다. 세부 스텝과 **그 스텝이 전체에서 어떤 위치인지** 를 함께 설명한다.
「검은 창 열기 → `⊞` 누르고 `cmd` 치고 `Enter`」 수준으로 구체적으로.

### ⑦ 프롬프트 발신 표기는 `[총괄 → 대상]`

`[정리 · 총괄]` 처럼 쓰면 «총괄이 하는 일» 로 읽힌다. belie 가 지적했다.
→ `[총괄 → NG-05]` · `[총괄 → 유휴 코드 세션]` 처럼 **받는 쪽을 명시**한다.
