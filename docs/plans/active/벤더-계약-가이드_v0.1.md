# 벤더 계약 가이드 v0.1 — 외부 연동 서비스 (통합관리시스템)

> 목적: 벤더 계약이 처음인 상황에서, MVP에 필요한 **외부 연동 3종**의 벤더 목록·기능·계약방법·비용·리드타임을 한 곳에 정리한다.
> 작성: 2026-07-21 · 근거: 각 벤더 공식 요금/개발 페이지(하단 출처). 단가는 모두 **VAT 별도**, 수시 변동 → 계약 직전 재확인 필요.
> 관련 결정: decision-inbox **DI-6**(벤더 계약, ⚡리드타임 김 → 개발보다 먼저 착수).

---

## 0. 왜 지금 계약해야 하나 (전체에서의 위치)

MVP 개발은 6~10주. 그런데 아래 서비스들은 **계약·심사·검수에 시간이 걸려서**, 개발 다 해놓고 붙이려 하면 그때 병목이 된다. 그래서 **개발과 병렬로 지금 문의를 걸어놔야** 일정이 안 밀린다. 특히 스크래핑(증빙조회)이 가장 오래 걸린다.

| 연동 종류 | 무엇에 쓰나 (우리 제품 기준) | 리드타임 | 급함 |
|---|---|---|---|
| ① 계좌·증빙 조회(스크래핑) | 고객 홈택스 세무자료·재무제표·납세증명·4대보험 자동수집 → 정책자금 심사/컨설팅 자동화 | **2~5주**(보안심사·계약) | ⚡최우선 |
| ② 알림톡·문자 | 고객 안내·리마인드·상태알림 발송 | **1~2주**(채널·템플릿 검수) | 중간 |
| ③ 전자세금계산서 발행 | 컨설팅 수수료 정산 시 세금계산서·현금영수증 발행/국세청 신고 | **3~7일**(연동계약) | 낮음 |

---

## ① 계좌·증빙 조회 — 스크래핑 / 마이데이터 API

**기능(우리에게 왜 필요한가):** 고객 동의를 받아 국세청 홈택스(부가세·소득·법인세 신고내역, 표준재무제표, 납세증명, 사업자등록상태), 4대보험 완납, 소득금액증명, 매입·매출 등을 **자동으로 끌어온다.** 정책자금 컨설팅의 심사·서류준비를 자동화하는 핵심.

| 벤더 | 특징 | 비용(감) | 계약/연동 방법 |
|---|---|---|---|
| **CODEF (헥토데이터)** ★추천 | 국내 최대 구독형 스크래핑 API. 홈택스·정부24·건강보험·은행·카드 등 방대. **간편인증(카카오·PASS·네이버·토스)** 로그인 지원 → 별도 본인인증 벤더 불필요 | 구독형+종량("쓴 만큼"). 상품별 상이, **정확단가는 콘솔 가입 후 상품별 표기 / 영업 견적**(요금계산기는 종료됨) | 개발콘솔 가입 → 상품신청 → 테스트키로 개발 → (민감상품) 계약·보안심사 → 운영키 |
| **쿠콘(Coocon)** | CODEF와 함께 스크래핑/마이데이터 원조급. B2B 계약형 | 견적(계약형) | 영업 문의 → 계약 |
| **바로빌 스크래핑 API** | 세금계산서 벤더가 홈택스 매입매출·사업자상태·카드/계좌조회도 제공 → ③과 원스톱 | 선불 포인트 + 협의 | 개발자센터 가입 → 계약 |
| 팝빌 홈택스수집·계좌조회 | **제한적**(세금계산서/현금영수증 매입매출 자동수신, 계좌조회만). 깊은 증빙(재무제표·납세·소득금액)은 커버 못함 → 보조용 | 홈택스수집 30,000원/월, 계좌조회 5,000원/월 | 회원가입 + (연동은 계약) |

**리드타임 ⚡2~5주** — 세무·금융 민감정보라 **보안심사·계약이 병목.** → 3종 중 **가장 먼저** 문의.
**주의:** 스크래핑은 "고객 본인 동의/인증" 기반이어야 함(무단 크롤링 금지 — 우리 확정사항과 일치).

## ② 알림톡 · 문자 (카카오 알림톡 + SMS/LMS)

**기능:** 고객 안내·예약 리마인드·진행상태 알림을 카카오 알림톡(정보성)과 문자로 발송. 발송 자체는 카카오 시스템이지만, **계약·연동은 "발송대행사(중계사)"를 통해** 한다.

| 벤더 | 알림톡 | SMS | LMS | 특징 |
|---|---|---|---|---|
| **솔라피(SOLAPI/쿨SMS)** ★개발친화 | **8원** | 13원 | 29원 | API·월기본료 무료, 건당차감. 문서 잘 돼있어 연동 쉬움 |
| **알리고(Aligo)** ★저가·간편 | 8~9원대 | 8~9원대 | 25원대 | 소규모 인기, 저렴 (※단가 계약 시 재확인) |
| **NHN Cloud / 비즈엠 / 인포뱅크** | 협의 | 협의 | 협의 | 대량·안정형(엔터프라이즈) |
| **팝빌 카카오톡·문자** | 12원 | 20원 | 50원 | ③ 세금계산서와 **원스톱**(단가는 다소 높음) |

**계약/연동 방법 (리드타임의 핵심):**
1. 대행사 가입
2. 카카오 **비즈니스 채널** 생성
3. **발신프로필 등록**(사업자정보 심사)
4. **알림톡 템플릿 등록 → 카카오 검수(영업일 1~5일)** — 승인된 템플릿만 발송 가능
5. 운영키 발급 + 소액 충전

**리드타임 1~2주**(채널·프로필·템플릿 검수 포함).
**팁:** 정책자금 안내·리마인드는 "정보성"이라 알림톡이 가장 싸고 적합. 광고성(홍보)은 친구톡/브랜드메시지로 분리(단가↑, 수신동의 필요).

## ③ 전자세금계산서 · 증빙 발행 (팝빌류)

**기능:** 컨설팅 수수료 정산 시 세금계산서 발행 + 국세청 신고, 현금영수증, (선택) 문자·팩스·계좌조회까지.

| 벤더 | 대표 단가(공식) | 특징 |
|---|---|---|
| **팝빌 (PopBill / ㈜링크허브)** ★추천 | 전자세금계산서 **200원/건**, 전자명세서 100원, 현금영수증 **0원(무료)**, 사업자상태조회 10원, 예금주조회 50~80원, 기업정보조회 100원, 알림톡 12원, SMS 20원, 팩스 50원/장. 정액: 홈택스수집 30,000원/월, 계좌조회 5,000원/월 | API 연동 무료·기본료 없음·포인트 차감, 최소충전 11,000원. **세금계산서+문자+계좌조회+홈택스수집 원스톱** |
| **바로빌 (BaroBill)** | 선불포인트, 연동요금 **협의** | 세금계산서+전자문서+문자+카카오+사업자/카드/계좌조회+홈택스 매입매출. 원스톱 |
| 스마트빌(비즈니스온)/Bill36524/더존 | 견적 | 대형·ERP 지향 |

**계약 방법:** 회원가입(사이트 일반사용은 무계약 즉시) → **API 연동개발은 계약 필수** → 테스트베드 개발 → 운영. (팝빌 연동문의 1600-8536 / 바로빌 파트너 1544-8385)
**리드타임 3~7일** — 3종 중 가장 빠름.

## 2. 첫 계약이면 이렇게 (추천 조합)

계약·연동 개수를 줄이는 게 초보자에겐 유리하다. 두 축이 있다:

- **원스톱형(팝빌 or 바로빌 1곳):** 세금계산서 + 문자/알림톡 + 계좌조회 + 홈택스수집을 한 계약으로. **단점:** 알림톡 단가 다소↑, **깊은 세무증빙(재무제표·납세·소득금액) 수집은 불가.**
- **전문 스크래핑(CODEF/쿠콘):** 정책자금 컨설팅의 핵심인 깊은 증빙 수집. 원스톱으로는 대체 불가 → **별도 필수.**

**권장 시작 구성 (2곳):**

| 용도 | 벤더 | 이유 |
|---|---|---|
| 증빙·세무자료 수집 | **CODEF(헥토데이터)** | 정책자금 심사 자동화의 핵심. 대체불가. ⚡먼저 계약 |
| 세금계산서(+문자·계좌조회 흡수) | **팝빌** | 무계약 가입으로 바로 테스트, 원스톱 |
| (선택) 알림톡 저단가 | 솔라피/알리고 | 발송량 많아지면 팝빌 대신 분리해 비용↓ |

→ **처음엔 CODEF + 팝빌 2곳으로 시작**, 알림톡은 일단 팝빌로 흡수했다가 물량 늘면 솔라피/알리고 추가.

## 3. 공통 계약·연동 절차 (스텝)

1. **서류 준비:** 사업자등록증, 대표자 정보 (발신프로필·계약에 필요)
2. 각 벤더 **개발콘솔 회원가입**
3. **테스트키(샌드박스)**로 연동 개발 — 실비용 없이 붙여보기
4. 계약/검수: (스크래핑·세금계산서 연동) 계약 체결 / (알림톡) 채널·발신프로필·템플릿 검수
5. **운영키 발급 + 포인트 충전**
6. 운영 모니터링 (잔여포인트 알림 등)

---

## 4. 월비용 시뮬레이션 (⚠️ 가정치 — 견적으로 대체 필요)

5인, 정책자금 컨설팅, 대략 가정:

| 항목 | 가정 | 월 비용(대략) |
|---|---|---|
| 증빙 스크래핑 | 고객 100건 × 증빙 5종 = 500회 조회 | 수만~십수만원(상품단가·견적 의존) |
| 알림톡 | 월 2,000건 × 8~12원 | 16,000~24,000원 |
| 세금계산서 | 월 200건 × 200원 | 40,000원 |
| **합계(감)** | | **월 10만~30만원대(가정)** |

정확한 값은 **CODEF/쿠콘 견적**과 실제 발송·발행량에 따라 결정. 위 표는 규모 감 잡기용.

## 5. 액션 체크리스트

- [ ] **CODEF** 개발콘솔 가입 + 필요한 홈택스/증빙 상품 목록 정리 → 영업 견적 문의 ⚡(먼저)
- [ ] (비교용) 쿠콘·바로빌 스크래핑 견적 1곳 더 받기
- [ ] **팝빌** 회원가입 → 테스트키로 세금계산서 발행 테스트
- [ ] **알림톡** 대행사 1곳(솔라피/알리고) 가입 → 카카오 채널·발신프로필 등록 → 템플릿 초안 만들어 검수 넣기
- [ ] 각 벤더 단가·최소사용료·계약조건 표로 취합 → 최종 벤더 확정(DI-6 종료)
