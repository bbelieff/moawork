# 정정 — 목업은 브라우저 없이 «글» 로 읽는다 (2026-08-10)

**전 세션 필독.** 배정 프롬프트 40개의 착수 6단계 ①번이 잘못 쓰였다. 아래로 대체한다.

## 무엇이 잘못됐나

프롬프트 ①번이 이렇게 돼 있다.

```
① docs/design/UI목업_워크스페이스_최종_v6.html 을 브라우저로 연다.
```

코덱스 세션이 이걸 실행하려다 막혔다 — `file://` 접근이 브라우저 보안 정책으로 차단되고,
우회는 금지돼 있다. **막힌 게 맞고, 우회하지 않은 판단도 맞다.**

잘못은 지시를 쓴 쪽(MW-총괄)에 있다. 목업은 «그림» 이 아니라 **명세**다. 글로 읽으면 된다.

## ①번을 이것으로 대체한다

```
 ① 목업을 «글» 로 읽는다 — 브라우저 필요 없다

      node docs/design/dump-mockup.mjs          ← 전체
      node docs/design/dump-mockup.mjs new      ← 탭 하나만 (new/contact/work/notice)

    탭 · 아이템(그룹) · 컬럼 · 타입 · 값의 출처 · 선택지 · 아이템 자동 이동 규칙
    · 탭을 넘기는 관문 · 자동계산 규칙이 전부 텍스트로 나온다.
    이 출력이 화면 대신이다. 이것만 보고 구현할 수 있어야 한다.

    ⚠️ file:// 로 목업을 열려고 하지 마라. 막히면 «우회하지 말고» 이 명령을 쓴다.
    ⚠️ 브라우저가 되는 세션(클로드 등)은 열어봐도 좋다. 다만 정본 판정은 위 명령 출력이다.
```

## 왜 이게 더 나은가

| | 브라우저로 보기 | `dump-mockup.mjs` |
| --- | --- | --- |
| 코덱스 세션 | ❌ 차단 | ✅ 됨 |
| 컬럼 타입·출처 | 눈으로 짐작 | 글로 명시 |
| 아이템 이동 규칙 | 눌러 봐야 앎 | 표로 나옴 |
| 옮겨 적기 | 손으로 베낌 | 복사 |
| 놓칠 위험 | 높음 | 낮음 |

화면을 «보는 것» 이 목적이 아니라 **무엇을 만들지 아는 것**이 목적이다. 글이 더 정확하다.

## 그래도 화면 확인은 남는다

만든 뒤 **눈으로 대조하는 단계는 그대로다.** 다만 그건 «내가 만든 화면» 을 보는 것이지
목업 파일을 여는 게 아니다. 클로드 세션은 자기 개발 서버(`http://localhost:3000`)를 열어
1440px · 375px 스크린샷을 찍는다. 코덱스 세션은 화면 증거가 필요하면 검수자에게 위임한다.

## 검사는 그대로

```
node docs/design/qa-mockup.mjs     ← 75개 전부 통과해야 착수
```

이것도 브라우저 없이 돈다. 하나라도 실패하면 착수 금지 · 작업반장 통지.
