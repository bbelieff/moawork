# PLAN-002 — 신규업체 보드 완성 릴리스

## 1. 목표·배경

먼데이 `🔥신규고객` 보드(서울경영지원센터) 대비 구조 격차를 메우고, UI를 공간 효율 기준으로
재설계한 뒤 `/newcust`를 릴리스한다. PLAN-001에서 이관된 `codex/bbe-newcust-monday-board-v1`
(26컬럼 복제 + cutover 026)을 기초로 쌓는다.

**범위 확정(사용자 2026-08-04)**: 먼데이 워크스페이스는 **구조만 복제**한다.
먼데이의 8,413건 실데이터 마이그레이션은 목표가 아니다. migration 026 cutover는
MoaWork 내부(001 CRM) 데이터만 대상으로 한다.

**용어 정의(사용자 확정 2026-08-04)**: **아이템 = 탭 안의 그룹**이다.
예: `신규업체-신규고객`, `신규업체-1차부재`, `신규업체-보류`. 본 문서의 모든 WO에서 이 의미로 쓴다.
(먼데이 API의 item(행)과 다른 MoaWork 고유 용어이므로 코드 명칭은 `sectionPreset` 등으로 혼동을 피한다.)

  ⓖ 기초 브랜치 rebase·통합·릴리스
