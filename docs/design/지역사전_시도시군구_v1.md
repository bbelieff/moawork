## 확인 필요

1. **"광주" 동명이인 문제** — 시도 "광주"(광주광역시)와 경기도 하위 "광주시"가 이름이 같다.
   UI 흐름은 시도를 먼저 고르고 그 안에서만 시군구를 고르는 구조(목업 확인, 캐스케이딩 드롭다운)라
   화면 조작으로는 헷갈릴 일이 없지만, **레거시 텍스트 파싱**(`경기_광주` 같은 값)에서는 반드시
   앞부분("경기")을 먼저 확정한 뒤에만 뒷부분("광주")을 그 시도 소속 시군구로 해석해야 한다.
   → `컬럼표준·마이그레이션매핑_v1.md`의 지역 분해 규칙에 명시.
2. **군위군 매칭 예외** — 2023.7.1 이전 등록된 레거시 옵션에 "경북_군위" 형태로 남아있을 수 있다.
   분해 규칙에서 시도=대구로 강제 재매핑하는 예외 처리 필요(→ 컬럼표준 문서에 반영).
3. **세종·제주 리드 0건** — 목업 시도 목록엔 있으나 R1/R2(레거시 실사용 옵션)엔 전혀 없다.
   실제 리드가 없는지, 다른 표기로 숨어 있는지 확인 필요.
4. **목업 시군구 예시 12개 전수 대조**: 화성시(경기)·남동구(인천)·김해시(경남)·사상구(부산)·

   강서구(**서울·부산 둘 다 있음** — 시도 스코프 안에서만 유일하므로 캐스케이딩 UI에서는 문제 없음)·
