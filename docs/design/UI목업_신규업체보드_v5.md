> 이 문서가 **검수 판정의 기준 정본**이다. 목업 HTML 파일 대신 이 명세로 대조한다.
> 근거: 총괄이 2026-08-04 belie와 v1→v5로 4회 반복 컨펌한 결과 · `docs/plans/ui-guidelines.md` 11원칙

## 0. 판정 방법

검수자는 1440px 스크린샷과 아래 항목을 1:1 대조해 ✅/❌ 를 남긴다.
❌ 가 있으면 사유를 항목 번호로 인용해 반려한다. **375/390px는 판정 대상이 아니다**(면제).

## 1. 레이아웃 골격 (원칙 2·3·8)

```
┌ 헤더 1줄 ────────────────────────────────────────────────────────┐
│ 🔥 신규업체   [전체][이대표][박정화 실장][미배정][＋]   ...   [새 업체] │
├ 필터 1줄 (줄바꿈 금지) ──────────────────────────────────────────┤
│ (⌕ 업체 검색) (담당자▾) (상담 상황: 상담 전 ×) (사업자 유형▾) (정렬▾)  (21/26) (CSV) │
├ 아이템 카드 ─────────────────────────────────────────────────────┤
│ ▾ ■ 신규고객   3건            계약금 합계 800만    (프리셋 칩)      │
│ ┌ 표 (전폭) ──────────────────────────────────────────────────┐ │
│ │ Name │ 신청일 │ 광고 명 │ 사업자 유형 │ 회사명 │ 연락처 │ 상담 상황 │ … │ │
│ └────────────────────────────────────────────────────────────┘ │
├ (그룹 간 여백) ──────────────────────────────────────────────────┤
│ ▾ ■ 1차 부재   2건   ← 이 그룹은 컬럼 배치가 다를 수 있다(독립)     │
└──────────────────────────────────────────────────────────────┘
```

| # | 항목 | 판정 기준 |
| --- | --- | --- |
| 1-1 | 기준 뷰포트 | **1440px**. 콘텐츠에 인위적 `max-width` 없음 |
| 1-2 | 컬럼 노출 | 가로 스크롤 없이 **12개 이상** 보임. 초과분은 가로 스크롤 |
| 1-3 | 헤더 | **1줄**. 제목·담당자 탭·새 항목이 한 줄에. 우상단 분리형 패널 금지 |
| 1-4 | 필터 | **1줄 고정**, 줄바꿈 금지. 넘치면 접기 또는 가로 스크롤 |
| 1-5 | 빈 상태 | 표 안 인라인 1~2줄 + 즉시 실행 액션. 전면 빈 화면 금지 |

## 2. 필터 — 칩 + 팝오버 (원칙 9)

| # | 항목 | 기준 |
| --- | --- | --- |
| 2-1 | 형태 | 네이티브 `<select>` 나열 **금지**. 알약형 칩 + 팝오버 |
| 2-2 | 활성 표시 | 값이 선택된 칩은 accent 틴트 + 해제(×) 노출 |
| 2-3 | 구성 | 검색 · 담당자 · 상담 상황 · 사업자 유형 · 정렬 · 컬럼 수(n/26) · CSV |
| 2-4 | 높이 | 26~28px, 한 줄 안에 정렬 |

## 3. 아이템(그룹) 카드 (원칙 10)

| # | 항목 | 기준 |
| --- | --- | --- |
| 3-1 | 형태 | 그룹마다 **독립 카드 블록**. 연속 나열 금지, 그룹 사이 여백 |
| 3-2 | 헤더 밴드 | 그룹색 연한 배경 + 진한 제목. `[접기▾] [그룹명] [건수]` 좌측 |
| 3-3 | 합계 | 헤더 밴드 **우측**에 합계(계약금 등) 또는 보조 정보 |
| 3-4 | 접기 | 접힌 그룹은 헤더만 남고 "N건 · 접힘" 표시 |
| 3-5 | 프리셋 칩 | 그룹 헤더 우측에 아이템 프리셋 이름 칩. 변경 시 "변경됨" 점 표시 |
| 3-6 | 그룹 수 | 시드 기준 **14개**(신규고객·1차 부재·2차 상담고객·담당자별 2·제조업 부재 2·2차 부재·2차 후 고민·관리·보류·해당안됨·거절·지원사업만) |

## 4. 표 (원칙 6)

| # | 항목 | 기준 |
| --- | --- | --- |
| 4-1 | 행 높이 | 34~40px |
| 4-2 | 고정 | 헤더 sticky · 첫 열(Name) sticky |
| 4-3 | 컬럼 순서 | **시드(먼데이 실측) 순서** — Name → 신청일 → 광고 명 → 사업자 유형 → 회사명 → 매출액 → 연락처 → … |
| 4-4 | 상태 셀 | 알약형 배지 + 시드에 정의된 색. 텍스트는 같은 색 계열 진한 톤 |
| 4-5 | 추가 행 | 표 마지막에 `＋ 업체 추가` 인라인 행 |

## 5. 드래그 재배치 (핵심 · 회귀 위험 높음)

| # | 항목 | 기준 |
| --- | --- | --- |
| 5-1 | 컬럼 | 머리글을 잡아 좌우로 순서 변경 |
| 5-2 | **그룹 독립** | **한 그룹의 컬럼 배치 변경이 다른 그룹에 영향을 주지 않는다.** 이 항목이 v5의 핵심 |
| 5-3 | 데이터 무결성 | 컬럼 **정의**는 보드 전역 유지, **배치·노출만** 그룹별 오버라이드로 저장 |
| 5-4 | 행 | 손잡이를 잡아 상하 이동 + **그룹 간 이동**. 이동 시 그룹 소속 갱신 + 활동로그 |
| 5-5 | 회귀 판정 | "에러 없음"이 아니라 **왕복 후 값이 남아 있음의 긍정 확인** |

## 6. 담당자 탭 (BBE-47 범위 밖 · WO-3)

상단 탭은 담당자별 필터다(전체·이대표·박정화 실장·미배정). WO-3에서 구현하며 여기서는 자리만 잡는다.

## 7. 블록 리스트 기반 (원칙: 재작업 방지)

탭 페이지는 **블록 리스트 구조**로 구현한다. 아이템(그룹)도 블록의 한 종류다.
이번 릴리스에는 아이템 블록만 존재하지만, 아이템 사이에 **노트·이미지·링크 블록**을 끼워 넣는
노션형 삽입(PLAN-003)이 **페이지 재작성 없이** 얹힐 수 있어야 한다.

## 8. 범위 경계 (2026-08-09 조정)

- CT06은 `components/newcust/**`·`lib/newcust/**`·`lib/boards/**`·`shell/nav-items.ts` 를 **편집하지 않는다**
  (코덱스 BBE-26 브랜치 점유 구역).
- 신규 파일 `app/src/components/board/**` 로 구현하고, `/newcust` 연결은 **WO-7 통합 시점**으로 이월한다.
