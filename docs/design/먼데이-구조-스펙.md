## 3. 수식 (그대로 재현 — DB generated column 또는 뷰)
- 업무관리: `수수료(원) = 실행액 × 수수료%` · `총매출액 = 계약금 + 수수료(원)` · `D+180 = 수수료입금일 +180` · `D+365 = +365`
- 회계: `금액 = 실행액 ÷ 100 × 수수료%` · `총매출 = 계약금 + 금액` · `D+180/365`
- ⚠ 업무관리 `수수료(원)=실행액×%`와 회계 `금액=실행액÷100×%`는 **% 해석이 다름**(전자는 %가 소수, 후자는 정수). 통일 검토(§7).
