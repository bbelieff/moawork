## 2. ★★ 가장 중요한 발견 — 「수금」은 «연도별 원장 보드» 다

`24년`·`25년`·`26년` 보드가 **정산 원장**이고, **그룹이 월별(1월~12월)** 이다.

```
24년 / 25년 / 26년   ← 보드 = 연
  ├ 1월 ┐
  ├ 2월 │  ← 그룹 = 월
  ├ …   │
  └ 12월┘
```

## 3. 업무관리 보드 — 실무 + 수금이 한 보드에 있다

`🔥업무관리`(409건) 컬럼에 위 수금 컬럼이 **그대로 또 있다**:
계약금 · 계약금_입금일 · 실행액 · 수수료(%) · 수수료(원)formula · 수수료_입금일 · 총 매출액 · D+180 · D+365

그룹: `⏹️준비단계` · `▶️진행중` · `🔂심사 중` · `💰승인` · `📂…접수예정`(4종) · `기업인증 진행` · `관리중` · `대출불가`

> **즉 실무 진행과 수금이 «같은 행» 에서 일어나고, 끝나면 연도 원장으로 옮겨 적는 흐름으로 보인다.**
> 이 «옮겨 적기» 가 자동인지 손인지는 먼데이 자동화를 더 봐야 한다 — **미확인**.

## 4. 마이그레이션 설계 — 기준을 «추가» 하는 구조

먼데이 전용으로 짜면 다음 CRM 에서 다시 짠다. **어댑터로 나눈다.**

```
파일 → [형식 감지] → [소스 어댑터] → 정규화 레코드 → [대상 매핑] → 앱 보드/컬럼
                        ↑
                  monday / (다음 CRM) / 일반 CSV
```

### 어댑터가 책임지는 것

```
① 헤더 행을 «찾는다»          ← 행 번호를 고정하지 마라
② 컬럼 제목 → 표준 필드 매핑
③ 그룹 행(월/단계) 인식
④ formula 컬럼 처리           ← 값을 «받되» 앱에서 재계산할지 정해야 한다
⑤ 타입 변환 (date · numbers · status · dropdown)
```

★ **헤더 행을 «알려진 컬럼 제목으로 찾는다».** 먼데이 내보내기는 보드 이름·빈 줄·헤더 순이지만,
그 배치는 버전에 따라 바뀔 수 있다. **행 번호를 박으면 다음 내보내기에서 깨진다.**
「회사명·대표자명·연락처 중 2개 이상이 한 행에 있으면 그게 헤더」 같은 규칙이 낫다.

### 표준 필드 (CRM 무관)

```
company_name · ceo_name · phone · email · address · industry · biz_type
region · founded_on · revenue · source_ad
deposit · deposit_paid_on · exec_amount · fee_percent · fee_paid_on
stage · assignee · memo · applied_on
```

## 5. ★ 아직 확인 못 한 것 — 여기를 채워야 구현이 정확해진다

- **실제 내보내기 파일의 물리적 형식.** API 구조는 확인했지만 **엑셀 파일 자체는 아직 못 봤다.**
  → 헤더 위치·그룹 행 표기·날짜 문자열 형식·formula 컬럼이 «값» 으로 나오는지 «수식» 으로 나오는지
  → **해결책: 내보낸 파일 하나를 저장소에 넣어 주시면 그 파일로 파서를 맞춘다**
    (`docs/design/samples/` 에 두고, 고객 고유값이 든 파일은 **커밋하지 않는다**)
- **먼데이 자동화**가 업무관리 → 연도 원장으로 «옮겨 적는지» 여부
- **8,439건 신규고객**을 다 가져올 것인가, 기간·상태로 잘라 올 것인가 (총괄 판단)
- `실행액` 의 뜻 — 대출 실행액인지 다른 것인지

## 6. UI/UX 방향 (초안)

```
① 파일 놓기          드래그앤드롭 · .xlsx/.csv
② 형식 감지 결과 보여주기   「먼데이 «업무관리» 형식으로 보입니다 — 컬럼 32개 중 28개를 알아봤습니다」
③ 매핑 확인·수정      못 알아본 컬럼만 사람이 고른다. 다 맞추라고 하지 않는다
④ 미리보기           상위 5행이 «앱 화면 모양» 으로 보인다. 여기서 되돌릴 수 있어야 한다
⑤ 가져오기           진행률 · 실패 행은 «건너뛰고» 끝에 목록으로
⑥ 결과              「N건 들어왔고 M건은 이래서 못 들어왔습니다」 + 다시 내려받기
```

★ **막다른 길 금지** — ③④에서 언제든 뒤로 갈 수 있어야 하고, ⑤가 중간에 실패해도
**들어간 것과 안 들어간 것을 사람이 알 수 있어야** 한다. 멱등키로 다시 올려도 중복이 안 생겨야 한다.
