체크리스트 관리자 위치 — 제 선택

고르라고 하셔서 골랐습니다.

후보좋은 점문제
프리셋 라이브러리에 「서류」 탭 선택 이미 「미리 정해두고 재사용하는 것」이 모이는 곳입니다(아이템 프리셋·뷰 프리셋). 서류 체크리스트도 정확히 그것 — 상품별로 미리 정해두고 새 업무마다 자동으로 깔립니다. 사용자가 「미리 정하는 건 저기」 한 곳만 기억하면 됩니다 목업에 탭이 둘뿐이라 세 번째를 새로 만드는 것이 목업과의 차이가 됩니다(총괄 승인 필요 — 그래서 여쭙는 것)
계정설정 › 회사와 팀 목업 변경 없음. 관리자 설정끼리 모임 여긴 「누가 쓰는가」(멤버·권한·로고)를 정하는 곳입니다. 서류 체크리스트는 「업무 내용의 기본값」이라 성격이 다릅니다. 정책자금 전용 항목이 일반 설정 사이에 끼면 다른 업종 회사에겐 뜬금없어 보입니다
계약업체 실무 보드 안 쓰는 자리 바로 옆 보드는 회사가 자유롭게 편집하는 데이터 영역입니다. 거기에 관리자 설정을 섞으면 「이건 지워도 되나」가 헷갈립니다
제 선택은 ①(프리셋 라이브러리 「서류」 탭) 입니다. 이유는 하나 — 서류 체크리스트는 프리셋입니다. 「상품별로 미리 정해두고 새 업무마다 재사용」이 프리셋의 정의 그대로고, 아이템·뷰 프리셋이 이미 그 자리에 있습니다. 목업에 없는 탭을 하나 늘리는 게 유일한 비용인데, 이건 목업이 그 기능을 안 그렸을 뿐이지 목업과 충돌하는 게 아닙니다.
