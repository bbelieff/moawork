## 1. 판정 요약

오늘 홈 taxonomy/ranking, 안전한 import, 직책/권한 분리, 작은 조직 성장 경로는 이미 허브에 있다. 즉시 회수할 공백은 개인정보 없는 지원 진단, 인라인 검증 오류, event 목적 분리, 안전한 Workspace export다. 댓글·멘션과 제한 preset 자동화는 실험, 좌석·수익화와 일반 삭제 복구는 백로그다.

## 3. 소비 순서

1. R1·R2를 먼저 설계해 새 핵심 도메인 없이 지원비와 실패 불신을 줄인다.
2. R3을 고정한 뒤에만 알림·멘션·자동화가 event를 소비한다.
3. R4는 import와 같은 tenant/capability·멱등·감사 원칙을 쓰되 별도 job으로 둔다.
4. E1·E2는 사용자 비교 전 승자가 아니며, B1·B2는 오늘 홈 DEV lease를 선점하지 않는다.
5. 코드 소비는 별도 DEV writer gate, 보안·권한은 T10, visual은 별도 VISUAL lease가 필요하다.

- T09: R1~R4 신규 허브 후보, E1~E2 실험, B1~B2 후순위로 병합한다. D1~D5는 재작성하지 않는다.
