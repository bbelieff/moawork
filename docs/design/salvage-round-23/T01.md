회수할 최소 계약:

```text
권한 없음
  → 필요한 capability와 요청 범위 설명
  → 승인 가능한 주체에게 요청
  → pending / approved / denied / expired
  → approved면 권한 version 재검증
  → 원래 작업으로 한 번만 복귀
```

원래 요청보다 넓은 권한 부여, Owner 관련 권한 요청, 타 tenant 요청은 생성 단계에서 거부한다.
