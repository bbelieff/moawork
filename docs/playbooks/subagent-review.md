# 독립 검토 양식

검토 대상과 필수 여부는 루트 `AGENTS.md §5`가 정한다. 이 양식은 별도 승인 단계를 만들지 않는다.

검토자에게 수용조건, PR/실제 SHA, diff, 관련 검사 결과를 전달한다. 부모의 합격 결론을 주입하지 않는다. Muse 등 외부 제공자에게 자료를 전달하기 전 공개 여부·전송 권한을 확인하고 비밀값·고객정보를 제외한다.

```text
과업: <GitHub Issue 또는 사용자가 맡긴 범위>
검토 대상: <PR, exact SHA, 파일>
수용조건: <사용자가 얻어야 하는 동작>
관련 검증: <실행 결과와 미실행 항목>

명세와 실제 변경을 비교하라. 발견한 문제는 심각도, 파일/행, 재현 또는 근거를 적어라.
실행하지 않은 검사는 NOT_RUN으로 구분하고, 중대한 미해결 문제와 후속 개선을 분리하라.
실제 모델·과업 ID·제공자 사용량/시간을 반환하되 미제공 값은 추정하지 마라.
```

P0/P1은 관련 릴리스를 차단한다. P2/P3는 GitHub Issue/Project에 후속으로 기록한다. 동일 GitHub 계정의 도구 검토를 독립 계정의 formal approval로 표현하지 않는다. takeover/supersedes의 기계 검증은 `scripts/merge-pr.mjs` 계약을 따른다.

관련 검사를 이미 통과했다면 그대로 증거로 소비한다. 새 변경·실패·미해결 위험 없이 전체 CI·build·화면 QA를 반복하지 않는다.
