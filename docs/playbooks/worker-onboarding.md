# 작업 인계 양식

개발 방식은 루트 `AGENTS.md`, 제품은 `CLAUDE.md`가 정한다. 이 파일은 별도 착수·승인 조건을 만들지 않는다.

```text
목표와 완료조건: <사용자 요청과 수용조건>
기존 승인 범위: <구현/병합/배포 등 실제 포함된 범위>
과업: <GitHub Issue, 현재 PR, 관련 작업>
작업 위치와 SHA: <실제 경로, 브랜치, base/head>
담당 범위: <파일·기능, 다른 활성 작성자와의 경계>
완료한 것과 증거: <실제 실행 결과>
남은 것: <미해결 findings·검증·재개 조건>
```

- 최신 main과 작업 트리 차이, 다른 활성 작업을 먼저 확인한다. 남의 변경을 덮어쓰지 않는다.
- 기본 브랜치는 `main`, 앱은 `app/`, 현재 웹 호스팅은 기존 VPS다. 운영 주소는 `https://www.moa-work.com`이다.
- 필요한 의존성만 설치한다. 환경 전용 도구 절차는 그 환경에서만 쓴다.
- 기존 완료 결과를 소비하고 남은 범위부터 진행한다. 과거 라운드 번호·담당자·고정 커밋 차이를 현재 상태로 재사용하지 않는다.
- 단독 작업은 책임자가 직접 마친다. 위임할 때만 실제 도구로 전달하고 진행을 확인한다. 댓글만 쓰고 다른 에이전트가 시작했다고 가정하지 않는다.
- 제품 검증과 문서 검증을 구분하고, 하지 않은 운영·UI 검사를 성공으로 보고하지 않는다.
