# 작업원 온보딩 — 모아워크 규칙 정본

새 코드세션이 착수 전에 읽는 문서. 붙여넣기용 킥오프 프롬프트는
`docs/plans/onboarding-moawork.md` 에 있다(이 문서가 규칙, 그쪽이 배포 양식).

## §0 전체 그림

- 레포: `github.com/bbelieff/moawork.git` · **기본 브랜치 `main`**(master 아님)
- 스택: Next.js(app) · Supabase(DB·Auth) · Node worker(pg-boss) · Vercel 배포
- canonical 도메인: `https://www.moa-work.com` (apex는 www로 308)
- 파이프라인: 총괄(설계) → 디스패치(회수·전달) → 작업 세션(구현) → 독립 검수 → 머지·배포

## §0-b 세션명

```
모아워크 <노트북|데탑> <C|G>T<01~10|작업반장>      C=클로드 · G=지피티(코덱스 등 GPT 계열)
서명: [모아워크 데탑 CT03(260809)]                공백 금지(데탑T03 ○ / 데탑 T03 ✗)
```

T번호는 **창 식별자일 뿐 전문분야가 아니다.** 구역은 착수 시 선언한 리스만 네 것이다.
같은 번호가 두 기기에 있어도 하는 일이 다르면 무방 — 충돌 판정 기준은 **파일**이다.
상세: `docs/plans/naming-rules.md`

## §0-c 공급자 소유권 (belie 확정 2026-08-09)

> **"코덱스가 할 일은 남겨놔"**

- `codex/*` 브랜치와 코덱스 구역 카드는 **CT(클로드) 세션의 인수·재배정·폐기 대상이 아니다.**
- 스테일해 보여도 상태만 정직하게 적고 사유는 **"코덱스 재개 대기"**, 소유는 코덱스에 유지한다.
- 인수하려면 **belie 개별 승인**이 필요하다. 승인 없이 codex 브랜치를 rebase·삭제·머지하지 않는다.
- 기승인 예외(2026-08-09): BBE-5(CT02) · BBE-44(CT03) · BBE-15(CT04) — "하던 거까지는 해".
- 반대로 `claude/*` 자산도 코덱스가 임의 인수하지 않는다. 소유 확인이 판정보다 먼저다.

## §1 리스(구역) 규칙

1. 잡는 파일을 **좁게** 선언한다. `app/src/**` 같은 통짜 선언 금지.
2. **먼저 선언한 쪽 우선.** 겹치면 나중 쪽이 비켜 다른 작업으로 간다(대기 금지).
3. 선언하지 않은 파일은 만지지 않는다. **새 파일 우선**, 기존 파일은 연결 한 줄만.
4. 브랜치는 **24시간 내 머지 또는 폐기.**
5. `docs/coordination/**` 는 디스패치(MWC) 단독 소유. 구현 세션은 수정하지 않는다.
6. Supabase 스키마는 **새 마이그레이션 파일로만** 추가. 기존 파일 수정 금지.
   번호는 머지 시점 최신+1 (main 최신 = `030`).

## §2 게이트와 실행 체인

```
① 최신 origin/main 위 rebase (충돌 시 임의 해결 금지·중단 보고)
② bash scripts/check.sh 초록   (lint + typecheck + test · pre-commit 훅 동일)
③ push → ④ PR(본문에 카드번호) → ⑤ CI(.github/workflows/ci.yml) 초록
⑥ 독립 검수(작성자 ≠ 검수자)
⑥′ 비주얼 확인 — UI 변경 시 스크린샷(1440 + 핵심 상호작용). 판정 주체는 **검수자 또는 총괄**
⑦ squash merge → ⑧ Vercel Production 배포 확인 → ⑨ /login HTTP 200 → ⑩ END 보고
```

**belie 승인을 기다리지 않는다(2026-08-09 확정).** 머지·배포까지 자율 완주한다.
belie에게 올리는 것은 ①고객 실데이터 비가역 변경 ②돈·보안 ③정책 방향 ④외부 발행 뿐이다.
문제가 생기면 revert가 복구 수단이다. Preview 촬영이 불가하면 로컬 `npm run dev` 화면으로 갈음하고
배포 후 프로덕션에서 재확인해 END 보고에 첨부한다 — **촬영 불가는 머지 중단 사유가 아니다.**
근거: `docs/plans/README.md` 자율 완주 정책

## §4 제품 규칙

- UI 어휘 = **"회사"**. URL·코드의 `workspace` 는 유지.
- **아이템 = 탭 안의 그룹**(예: 신규업체-신규고객). 먼데이 API의 item(행)과 다르다.
  코드 명칭은 `sectionPreset` 등으로 쓴다.
- **프리셋** = 아이템 단위 구조 템플릿. 저장소는 워크스페이스 공용 라이브러리.
- 기준 뷰포트 **1440px**. **375/390px 검증 면제**(belie 2026-08-05, 모바일은 추후 영업자용 별도 제품).
  과거 문서의 "375px 무깨짐" 조항은 무효.
- 브랜드 토큰 하드코딩 금지(Coral은 담당자·멘션·알림 전용) · 터치 44px+
- 뱃지: 숫자 = 내가 할 일 / 점 = 안 본 변화 / 99+ 절단
- PostHog US 리전 · 프록시 필수(`app/src/proxy.ts`) · PII 전송 금지
- 비밀값·토큰·연결문자열은 출력·기록·커밋 금지(변수명과 유무만)
