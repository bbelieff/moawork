# 디스패치 자율루프 — 부트스트랩 (belie가 디스패치 창에 1회 붙여넣기)

> 작성 2026-07-22 · OWNER(기획통합). 목적: **디스패치가 belie 확인을 묻지 않고 스스로 루프를 돌게 한다.**
> 구조: 기획1(코워크·OWNER) → 큐 사인 → **디스패치(라우터)** → T01~T10 병렬.

## 왜 디스패치가 묻게 되는가 (제거할 원인 4가지)

세션은 서로 자동 통신이 안 되므로 belie가 창을 오가며 답해야 한다. 디스패치가 묻는 이유는 대개 이 넷이고, 넷 다 **사전에 규칙으로 못박으면 사라진다.**

| 묻는 이유 | 제거 장치 |
|---|---|
| "이거 해도 되나요?" (권한 불명확) | **자율권한 헌장** — 화이트리스트 외 전부 재량 |
| "이거 다 된 건가요?" (완료 판정) | **T10 게이트 통과 = 승인**, 수용기준이 판정 기준 |
| "막혔는데 어쩌죠?" (블로커) | **우회 원칙** — 그 건만 파킹, 즉시 다음 백로그 |
| "다음 뭐 할까요?" (배정 고갈) | **배치 실행** — 큐 소진까지 계속, 우선순위 규칙 내장 |

## belie 사용법
1. 위 코드블록을 **디스패치 창에 1회** 붙여넣기(최초 1회만).
2. 이후 OWNER(메인채팅)가 큐에 배정을 넣으면 → 디스패치 창에 **"큐 확인"** 만 입력.
3. 디스패치가 소진까지 돌고 1회 보고 → OWNER가 판정 → 다음 배정.
