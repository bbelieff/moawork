# 워크로그 규약

> **모든 세션(기획·코드트랙)은 시작과 끝에 상세 기록.** 이게 Claude↔Codex 인수의 유일한 다리 — 한도는 예고 없이 끝난다.

- 파일명: `YYYY-MM-DD_<세션명>.md` (예: `2026-07-20_기획.md`, `2026-07-21_track-03.md`). 같은 트랙이 여러 날이면 날짜별로 새 파일.
- 한 파일 안: **START 블록**(작업 시작 시) → 중간 **CHECKPOINT** 여러 개 → **END 블록**(종료 전). 템플릿: `_TEMPLATE.md`.
- 이 로그는 **append 위주**(덮어쓰지 말 것). 현황판은 `session-registry.md`와 마스터기획서가 담당.
- 최소 기록 시점: 착수·결정·구현·검사·PR·머지 전후·배포·블로커·종료 전.

## 왜 (초보자용)
다음 세션(다른 Claude거나 Codex)이 이 파일만 읽고 **정확히 이어받게** 하기 위함입니다. 항상 이 4개가 있어야 해요: **무엇을 · 왜 · 어디까지 했나 · 다음은 뭔가.**
