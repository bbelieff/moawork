# ADR-0004 — 트랙 격리 · 공용계약 변경 · 런타임 검증 (하네스)

- 날짜: 2026-07-21 · 상태: **승인(오케스트레이터 판정)** · 계기: T03·T06·T10 공유 워킹트리 교차오염 보고

## 맥락
코드트랙들이 **하나의 공유 워킹트리**에서 작업 → ① 커밋 레이스(T03: 타 트랙 파일 스윕) ② `check.sh`가 워킹트리 전체 검사 → 타 트랙 미완성 코드(T09 types.ts TS2305)로 T06·T10 커밋 차단. 근본 원인 = **원격 레포 미push(DI-4)** 라 모두가 단일 로컬 폴더에서 작업.

## 결정
### 1) 트랙 격리 (병렬 구현·직렬 머지 복원 — 플레이북 §4)
- **한 트랙 = 한 격리 작업본.** 공유 워킹트리 커밋 금지.
- 방법 A(권장, push 후): 트랙별 개별 clone. 방법 B(로컬 즉시): `git worktree`.
  ```bash
  git worktree add ../wt-t02 -b feat/t02-boards-engine
  git worktree add ../wt-t04 -b feat/t04-dash
  # 각 트랙은 자기 worktree에서만 편집 → 파일시스템 격리, 레이스 0
  ```
- `check.sh`/pre-commit은 **자기 브랜치 트리 기준**(격리 worktree면 자동으로 main+자기 변경만 검사). 공유 폴더에서 전체 검사 금지. 임시로 공유가 불가피하면 typecheck/lint를 **변경 파일 스코프**(`git diff --name-only origin/main`)로 제한.
- 머지는 **한 번에 하나**, 선행 머지 후 후행 rebase+재검증.

### 2) 공용 계약은 소유자만 (단독 선행 PR)
- `lib/types`·`lib/repo/index.ts`(Repo 포트)·`supabase/migrations/*` = **공용 계약**. 트랙이 독자 수정 금지.
- 변경 필요 시 소유자에게 요청: 타입·Repo 포트 = **T03**(파운데이션), 스키마 = **기획 세션**. 소유자가 단일 선행 PR로 반영 후 타 트랙 rebase.

### 3) 런타임 검증 = 완료 판정의 일부 (CI 초록 ≠ 완료)
- lint+typecheck+test 통과는 필요조건일 뿐. **`npm run dev` 클릭스루 스모크**(로그인→온보딩→홈→보드)를 **T10(게이트키퍼)** 가 실행해 "완료" 판정. (플레이북: 완료는 실측)

## 결과
- 교차오염 3건(T03·T06·T10) 해소. T09 리팩터가 남을 막지 않음.
- 근본 해소 = DI-4(원격 push). 그 전까지 worktree로 격리.
