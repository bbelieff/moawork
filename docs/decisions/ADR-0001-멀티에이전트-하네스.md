# ADR-0001 — 멀티에이전트 하네스 (Claude 주력 + Codex 인수)

- 날짜: 2026-07-20 · 상태: **승인**(사용자 지시)

## 맥락
- Claude 사용량(한도)이 작아 장시간 연속 작업이 끊긴다. 디스패치발 코드 트랙 10개 예정.
- 경영일지 프로젝트에서 검증된 오케스트레이션/연속성 패턴(PRODUCT-PLAYBOOK §4) 존재.

## 결정
- **Claude를 주력(원본), Codex를 인수**로 하는 **대칭 멀티에이전트**. 같은 이름의 세션을 양 제공자에 생성.
- 진입점 쌍(`CLAUDE.md`/`AGENTS.md`)은 **공통 정본**(`docs/coordination/README.md`)을 가리키고, 규칙은 **에이전트 중립** 언어.
- 인수의 다리 = **워크로그(세션 시작/끝 상세기록) + session-registry + provider-status**.
- **경영일지와 같은 GitHub 계정, 새 레포**로 진행.
- 오케스트레이터(기획) 세션은 **git 명령 미실행**(플레이북 §7 index.lock 사고).

## 결과
- 한도 소진이 작업 손실로 이어지지 않음(워크로그로 이어받음). active_controller 1명 규칙으로 동시 지휘 충돌 방지.

## 대안 (기각)
- 단일 Claude: 한도로 중단 위험. Codex 단독: 사용자가 Claude 우선.
